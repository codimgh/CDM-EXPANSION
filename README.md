**CDM-EXPANSION** 

Is a browser extension that extends the capabilities of the Taplink website builder. It adds a "My Blocks" section to the admin interface — a personal collection of ready-made blocks that can be placed on a page in one click. The extension makes it easy to add a variety of elements to pages: widgets, buttons, sliders and other customizable blocks. All blocks live in the author's personal collection and sync with the server, so the set is constantly growing.

The key feature is the built-in code generators (configurators). With them, users can customize a block's appearance — sizes, colors, fonts, spacing — without any knowledge of HTML or CSS. Settings are applied visually and take effect on the page immediately. The extension includes an activation and access control mechanism: every block is tied to the page owner and works only for authorized users. This protects content from copying and unauthorized use.
