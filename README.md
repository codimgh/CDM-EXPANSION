**CDM-EXPANSION** 

This is an extension for Chromium‑based browsers that enhances the capabilities of the Tp link website builder. It adds a collection of ready‑made blocks, website templates, and widgets to the administrator interface; these can be customized and placed on the website page. All blocks, templates, and widgets are stored in the author’s personal collection and are synchronized with the server, so the set is constantly being updated.

The key feature is the built‑in code generators (configurators). With their help, you can customize the appearance of blocks, templates, and widgets — sizes, colors, fonts, spacing, and other elements — without any knowledge of HTML, CSS, or JS. The settings are applied visually and immediately applied to the element, and they are displayed on the active page of the website.

The extension includes an activation and access control mechanism: each block, template, or widget is linked to the page owner and works only for authorized users of the extension, which protects the content from copying and unauthorized use.
